↗Aggregate timeline

全 repo の日次合算。クローラ wave は同日に複数 repo に出るため、ここで山が立つ。最高記録日を注釈表示。

🏆Per-repo leaderboard

累積 unique cloners 順。各 repo の clones (青) と views (緑) を全期間、スケールは repo ごとに独立。直近 7 日 vs 前 7 日の勢いを矢印で。

⚖Clones : Views ratio

ratio = sum(clones) ÷ max(sum(views), 1)。値が大きいほど人間 view が薄く、bot/crawler/CI clone が支配的 — つまりこのダッシュボードが clone 駆動である理由。

▤Co-traffic correlation

repo ペア間の日次 unique cloners の Spearman 順位相関 (全期間、欠損日は 0 埋め)。Spearman は単日 spike に引きずられず、uniques は CI/refetch ノイズを除いた "実 entity 数" 寄りなので、関連トピック / リリース連動が見えやすい。対角は自明に 1.0。

retrieval: discoverable now ・ parametric: watch it climb
