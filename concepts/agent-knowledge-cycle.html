Agent Knowledge Cycle (エージェント知識サイクル)

Research-line name · Agent Knowledge Cycle · also known as AKC

Six composable phases — Research, Extract, Curate, Promote, Measure, Maintain — by which an agent's experience becomes durable, behavior-shaping knowledge, with human approval required on every change to the agent's future behavior. Its core is the growth cycle: experience becomes reusable knowledge, reusable knowledge changes future behavior, and the loop sharpens human judgment as it runs. The cycle is portable across harnesses and genre-neutral: the same six phases run on behavioral patterns, domain expertise, or constitutional values.

Coined by shimo4228 as the name of the Agent Knowledge Cycle practice line.

エージェント知識サイクル（日本語）

エージェントの経験を durable で行動を形づくる知識へ変える 6 つの composable な phase — Research, Extract, Curate, Promote, Measure, Maintain。エージェントの将来の行動を変えるすべての変更に人間の承認を要求する。核は成長サイクル: 経験が再利用可能な知識になり、知識が将来の行動を変え、ループが回るほど人間の判断が研ぎ澄まされる。harness 間で portable であり、genre-neutral — 同じ 6 phase が行動パターン・ドメイン知識・constitutional values の上で回る。
