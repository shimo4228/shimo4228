Attention ceiling

Coined term · Agent Knowledge Cycle

The limit the operator's attention and judgment place on a human-agent loop — a budget that does not grow with the model, and that grows relatively scarcer as agent capability does. It is AKC's organizing design axis: every phase is shaped to spend the budget only where judgment is irreplaceable. The repository hedges the constraint as a contemporary claim about 2026-era human-agent work, not an eternal law.

Coined by Tatsuya Shimomoto (shimo4228) within the Agent Knowledge Cycle practice line (ADR-0010).
